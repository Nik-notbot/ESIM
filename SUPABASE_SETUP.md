# Настройка нового проекта Supabase

Похоже, что ваш текущий проект Supabase (`nwcleyhnbzxetcqtlim`) недоступен. Возможные причины:
- Проект был удален
- Истек срок бесплатного плана
- Проект был приостановлен из-за неактивности

## Временное решение (уже реализовано)

Сейчас сайт работает без Supabase:
- Заказы сохраняются в localStorage браузера
- Платежи создаются через Wata API
- После оплаты клиент получает инструкции для связи с поддержкой

## Создание нового проекта Supabase (если нужно)

1. **Создайте новый проект:**
   - Зайдите на https://app.supabase.com
   - Создайте новый проект
   - Запомните URL и ключи

2. **Создайте таблицы:**
   - Используйте SQL из `database_schema.sql`

3. **Обновите конфигурацию:**
   - Замените URL и ключи во всех файлах:
     - payment.js
     - success.js
     - netlify/functions/supabase-api.js

## Текущий процесс работы (без БД)

1. Клиент выбирает тариф и заполняет форму
2. Создается платеж в Wata API
3. После оплаты клиент видит страницу с инструкциями
4. Клиент отправляет номер заказа в Telegram
5. Менеджер вручную отправляет QR-код
