# 🤖 Настройка уведомлений для нескольких пользователей Telegram

## 🎯 **Обзор**

Обновлена система уведомлений для поддержки отправки сообщений нескольким пользователям Telegram одновременно.

## 🚀 **Новые возможности**

### **✅ Поддержка множественных получателей:**
- **Один пользователь** - как раньше
- **Несколько пользователей** - через запятую
- **Гибкая настройка** - легко добавлять/удалять пользователей

### **✅ Улучшенная обработка ошибок:**
- **Частичный успех** - если одному пользователю не удалось отправить
- **Подробные логи** - для каждого получателя отдельно
- **Статистика отправки** - количество успешных/неудачных отправок

## 🔧 **Настройка в Netlify**

### **Вариант 1: Один пользователь (как раньше)**
```
TELEGRAM_CHAT_ID = 123456789
```

### **Вариант 2: Несколько пользователей (новое)**
```
TELEGRAM_CHAT_IDS = 123456789,987654321,555666777
```

### **Обратная совместимость:**
- ✅ **Старая переменная** `TELEGRAM_CHAT_ID` продолжает работать
- ✅ **Новая переменная** `TELEGRAM_CHAT_IDS` имеет приоритет
- ✅ **Автоматическое определение** количества получателей

## 📋 **Как получить Chat ID пользователей**

### **Метод 1: Через бота @userinfobot**
1. **Попросите пользователя** написать боту @userinfobot
2. **Бот вернет** Chat ID пользователя
3. **Скопируйте** числовой ID

### **Метод 2: Через вашего бота**
1. **Пользователь пишет** вашему боту команду `/start`
2. **Проверьте логи** в Netlify Functions
3. **Найдите Chat ID** в логах

### **Метод 3: Через API Telegram**
```bash
curl "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates"
```

## 🛠️ **Настройка в Netlify Dashboard**

### **1. Зайдите в Site Settings:**
- **Netlify Dashboard** → Ваш сайт → **Site settings**

### **2. Перейдите в Environment Variables:**
- **Build & deploy** → **Environment variables**

### **3. Добавьте/обновите переменные:**
```
TELEGRAM_BOT_TOKEN = ваш_токен_бота
TELEGRAM_CHAT_IDS = 123456789,987654321,555666777
```

### **4. Сохраните изменения:**
- **Нажмите "Save"**
- **Перезапустите сайт** (если нужно)

## 📊 **Примеры настройки**

### **Для команды из 3 человек:**
```
TELEGRAM_CHAT_IDS = 123456789,987654321,555666777
```

### **Для команды из 5 человек:**
```

```

### **С пробелами (автоматически очищаются):**
```

```

## 🔍 **Проверка работы**

### **1. Протестируйте уведомления:**
После настройки переменных:
- **Сделайте тестовую покупку** на сайте
- **Проверьте логи** в Netlify Functions
- **Убедитесь** что все пользователи получили уведомления

### **2. Проверьте логи:**
В логах должно быть:
```
Sending notification to chat ID: 123456789
Telegram notification sent to 123456789: 12345
Sending notification to chat ID: 987654321
Telegram notification sent to 987654321: 12346
```

### **3. Ожидаемый ответ функции:**
```json
{
  "success": true,
  "message": "Notifications sent: 3 success, 0 errors",
  "results": [
    { "chatId": "123456789", "messageId": 12345, "success": true },
    { "chatId": "987654321", "messageId": 12346, "success": true },
    { "chatId": "555666777", "messageId": 12347, "success": true }
  ],
  "errors": [],
  "total_recipients": 3
}
```

## 🚨 **Обработка ошибок**

### **Если один пользователь недоступен:**
```json
{
  "success": true,
  "message": "Notifications sent: 2 success, 1 errors",
  "results": [
    { "chatId": "123456789", "messageId": 12345, "success": true },
    { "chatId": "987654321", "messageId": 12346, "success": true }
  ],
  "errors": [
    { "chatId": "555666777", "error": "Forbidden: bot was blocked by the user" }
  ],
  "total_recipients": 3
}
```

### **Возможные ошибки:**
- **"Forbidden: bot was blocked by the user"** - пользователь заблокировал бота
- **"Bad Request: chat not found"** - неправильный Chat ID
- **"Too Many Requests"** - превышен лимит запросов

## 🔧 **Управление пользователями**

### **Добавить нового пользователя:**
1. **Получите Chat ID** нового пользователя
2. **Добавьте в переменную** `TELEGRAM_CHAT_IDS`
3. **Сохраните** в Netlify
4. **Протестируйте** отправку

### **Удалить пользователя:**
1. **Удалите Chat ID** из переменной `TELEGRAM_CHAT_IDS`
2. **Сохраните** в Netlify
3. **Проверьте** что уведомления больше не приходят

### **Временно отключить уведомления:**
1. **Удалите** переменную `TELEGRAM_CHAT_IDS`
2. **Или установите** пустое значение
3. **Уведомления** перестанут отправляться
