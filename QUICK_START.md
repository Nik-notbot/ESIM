# Быстрый запуск eSIM Store

## 1. Настройка Supabase (5 минут)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com)
2. Создайте новый проект
3. Перейдите в SQL Editor
4. Скопируйте содержимое файла `database/schema.sql` и выполните
5. В настройках проекта (Settings → API) скопируйте:
   - Project URL
   - anon public key
   - service_role key (для webhook)

## 2. Настройка конфигурации (2 минуты)

Откройте файл `config.js` и вставьте скопированные данные:

```javascript
supabase: {
    url: 'https://ваш-проект.supabase.co',
    anonKey: 'ваш-anon-key',
    serviceKey: 'ваш-service-key'
},
```

## 3. Добавление QR-кодов

В том же файле `config.js` добавьте ваши QR-коды:

```javascript
qrCodes: [
    'https://ibb.co/TxNLKx3x',
    'https://ibb.co/xxxxxxx',
    // добавьте больше ссылок
]
```

## 4. Запуск сайта

### Вариант 1: Локальный сервер (для тестирования)

Если у вас установлен Python:
```bash
python -m http.server 8000
```

Или с Node.js:
```bash
npx http-server
```

Откройте в браузере: http://localhost:8000

### Вариант 2: Размещение на хостинге

Загрузите все файлы (кроме папки `api`) на ваш веб-хостинг.

## 5. Настройка Webhook (опционально)

Для автоматического обновления статусов платежей:

1. Перейдите в папку `api`:
   ```bash
   cd api
   npm install
   ```

2. Создайте файл `.env` на основе `.env.example`

3. Запустите сервер:
   ```bash
   npm start
   ```

4. В настройках WATA укажите webhook URL: `https://ваш-сервер.com/api/webhook`

## 6. Тестирование

1. Откройте главную страницу
2. Выберите тариф и нажмите "Купить"
3. На странице оплаты увидите информацию о тарифе
4. Заполните контактные данные (опционально)
5. Нажмите "Перейти к оплате"

В демо-режиме (без настроенной БД) сайт будет работать с ограниченным функционалом.

## Проблемы и решения

**Ошибка "База данных не подключена"**
- Проверьте правильность URL и ключей в `config.js`
- Убедитесь, что таблицы созданы в Supabase

**Кнопки "Купить" не работают**
- Проверьте консоль браузера (F12)
- Убедитесь, что файл `config.js` подключен перед `script.js`

**QR-код не отображается**
- Добавьте больше QR-кодов в `config.js`
- Проверьте, что ссылки на изображения активны
