# 🤖 Настройка Telegram Bot для уведомлений о продажах

## 🎯 **Что будет реализовано:**

- 🔔 **Мгновенные уведомления** о каждой продаже
- 📊 **Детальная информация** о заказе
- 📱 **Мобильные уведомления** на телефон
- 📈 **Статистика продаж** в реальном времени

## 🚀 **Пошаговая настройка:**

### **Шаг 1: Создание Telegram Bot**

1. **Откройте Telegram** и найдите бота `@BotFather`
2. **Отправьте команду** `/newbot`
3. **Введите название** бота (например: "eSIM Store Notifications")
4. **Введите username** бота (например: "esim_store_notifications_bot")
5. **Сохраните токен** бота (выглядит как: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### **Шаг 2: Получение Chat ID**

1. **Напишите боту** любое сообщение
2. **Откройте в браузере**: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
3. **Найдите** `"chat":{"id":123456789}` - это ваш Chat ID
4. **Сохраните Chat ID**

### **Шаг 3: Настройка переменных окружения в Netlify**

1. **Зайдите в Netlify Dashboard**
2. **Выберите ваш сайт**
3. **Site settings → Environment variables**
4. **Добавьте переменные:**

```
TELEGRAM_BOT_TOKEN = 123456789:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHAT_ID = 123456789
```

### **Шаг 4: Перезапуск деплоя**

После добавления переменных:
1. **Deploys → Trigger deploy → Deploy site**
2. **Дождитесь завершения** деплоя

## 🧪 **Тестирование:**

### **Автоматическое тестирование:**
1. **Сделайте тестовую покупку** на сайте

## 🔍 **Отладка:**

### **Проверка переменных окружения:**
```bash
# Через Netlify CLI
netlify env:list
```

### **Проверка логов:**
1. **Netlify Dashboard → Functions**
2. **send-telegram-notification**
3. **Проверьте логи** на наличие ошибок

### **Частые проблемы:**

1. **"Bot token is invalid"**
   - Проверьте правильность токена
   - Убедитесь, что токен скопирован полностью

2. **"Chat not found"**
   - Проверьте правильность Chat ID
   - Убедитесь, что вы написали боту сообщение

3. **"Forbidden: bot was blocked"**
   - Разблокируйте бота в Telegram
   - Напишите боту команду `/start`
