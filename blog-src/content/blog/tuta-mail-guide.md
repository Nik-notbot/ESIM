- tutamail.com

Для всех доменов используется единая страница входа: [tuta.com/ru](https://tuta.com/ru)

## 2. Вход в почтовый ящик

Вы можете пользоваться:
- веб-версией [Tuta](https://tuta.com/ru)
- приложением для [Android](https://play.google.com/store/apps/details?id=de.tutao.tutanota) или [iOS](https://apps.apple.com/ru/app/tuta-encrypted-email-app/id922429609)

Для авторизации:
1. Введите логин (полный адрес почты)
2. Укажите пароль
3. Введите код двухфакторной аутентификации (2FA)

## 3. Настройки и безопасность

Чтобы почта работала стабильно и была защищена, рекомендуем пройти основные настройки.

Откройте: **Настройки (шестерёнка) → Настройки пользователя → Вход**

### 3.1. Проверка активных сессий

Рекомендуем убедиться, что доступ к ящику есть только у вас!

- В разделе **Текущие сессии** удалите все лишние авторизации
- Входы с вашего устройства могут отображаться как `<Этот клиент>` — это нормально

### 3.2. Изменение пароля

1. Откройте раздел **Учётные данные для входа**
2. Установите новый пароль

Желательно делать это при получении почты впервые.

### 3.3. Обновление кода восстановления

В разделе **Код восстановления → Обновить**

**Код восстановления** — единственный способ вернуть доступ в случае утери пароля или 2FA. Запишите новый код и храните его в надёжном месте.

### 3.4. Обновление 2FA

1. Пролистайте до раздела **Двухфакторная аутентификация (TOTP)**
2. Удалите старый токен → введите пароль
3. Добавьте новый через **Google Authenticator**, **Aegis** или **2FAS**
4. Введите 6-значный код подтверждения

## 4. Настройка фильтрации спама

Если код подтверждения попал в **Спам** — нужно настроить фильтрацию.

1. Откройте **Настройки → Настройки администратора → Правила для спама**
2. Нажмите **Показать** → добавьте правило (значок **+**)
3. Укажите адрес отправителя, например: `do-not-reply@ses.redotpay.com`
4. Нажмите **Окей**
