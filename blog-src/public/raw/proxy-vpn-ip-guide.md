## Что такое IP и прокси?

**IP-адрес** — это ваша «визитка» в интернете. Сайты видят вашу страну, город, провайдера.

**Прокси** — посредник между вами и интернетом. Сайт видит IP прокси, а не ваш.

**Важно:** прокси работает только в том приложении, где включён. Telegram, игры, банки — идут напрямую.

![Типы прокси](https://i.postimg.cc/9MT4fyvF/cf5adaed-b9af-47a8-a302-b83ecd1cd8ef.png)

## Типы прокси

### Residential (резидентские)
IP домашних подключений. Максимальное доверие, подходят для платёжек. Дорогие.

### Mobile (мобильные)
IP от операторов 4G/5G. **Самый высокий уровень доверия**. Дорогие.

### Datacenter (серверные)
IP из дата-центров. Быстрые и дешёвые, но **не подходят для платёжек** — сразу видно что не человек.

![Сравнение](https://i.postimg.cc/PxT6x7YT/d97c75ec-b574-4649-a831-eb9a549ee076.png)

### Дополнительно:
- **Rotating** — IP меняется автоматически
- **Static** — постоянный IP
- **Shared** — один IP на несколько клиентов (рискованно)
- **Private** — только ваш IP

## Прокси vs VPN: что выбрать?

### Для стриминга (Netflix, YouTube, Spotify)
Подойдёт **любой VPN** — сервисам важна только страна.

### Для платёжек и криптобирж
Нужны **Residential/Mobile прокси** или **приватный VPN**. Антифрод проверяет историю IP, чистоту, географию.

## 6 ошибок → блокировка

1. **Регион VPN ≠ billing-адрес** — мгновенный флаг
2. **Утечка IP через WebRTC** — отключайте в браузере
3. **Русский fingerprint + европейский VPN** — подозрительно
4. **Частая смена IP** — выглядит как телепортация
5. **«Грязные» IP** от других пользователей
6. **Вход с разных IP** за короткое время

**Главное правило: консистентность.**
