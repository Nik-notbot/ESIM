## Как сменить страну/регион Apple ID?

Перед началом убедись, что тебе требуется:
- скачать/обновить нужные приложения, недоступные в текущем регионе
- добавить карту в Apple Pay (регион Apple ID влияет на доступность)

### Если кнопка смены страны недоступна

Проверь, все ли выполнено:

**1. Баланс Apple ID = 0.00**

На Apple ID не должно оставаться ни копейки — иначе Apple не даст сменить страну.

**2. Нет активных подписок**

**Настройки → [имя] → Подписки** → отмени все и дождись окончания.

**3. Нет предзаказов/аренд/открытых споров**

**4. Выйти из Family Sharing**

### Порядок действий:

1. Открой **Настройки** → тапни по Apple ID
2. **Контент и покупки** → **Просмотреть**
3. **Страна/регион** → **Изменить**
4. Выбери страну (США, Канада или Пуэрто-Рико)
5. Укажи карту с правильным биллинговым адресом
6. Перезапусти App Store и Wallet

**Совет:** На время смены лучше **отключить VPN**.

## Как добавить карту Ether.fi / Wise в Apple Wallet?

1. Открой приложение **ether.fi** или **Wise**
2. Зайди в раздел карты → **Add to Apple Wallet**
3. Подтверди через **SMS**, **приложение** или **e-mail**
4. Дождись статуса **Card Added**
5. Проверь карту в **Wallet**

### Если что-то не работает

| Проблема | Решение |
|----------|---------|
| Нет кнопки "Add to Apple Wallet" | Обнови iOS и приложение |
| Код не приходит | Проверь номер/email, отключи VPN |
| "Contact Issuer" | Открой приложение — там ждёт подтверждение |
| Отказы при оплате | Уменьши сумму, попробуй другого мерчанта |

### Важно про адрес для Ether.fi

BIN карты — Puerto Rico. Указывай:

- **Country:** United States
- **State:** PR
- **City:** San Juan
- **ZIP:** 00911

## Как добавить карту через Wallet напрямую

![Wallet](https://i.postimg.cc/qqr85RWt/2025-11-11-16-54-36.jpg)

1. **Wallet** → нажми **"+"**
2. Выбери **«Дебетовая или кредитная карта»**
3. Введи данные (номер, срок, CVC)
4. Подтверди через SMS/email
5. Готово!
