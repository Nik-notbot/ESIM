# 📝 Настройка скрытых заметок для QR-кодов

## 🎯 **Что добавлено:**

Новый столбец `hidden_notes` в таблице `qr_codes` для внутренних заметок администратора.

## 🔒 **Безопасность:**

- ✅ **Скрытые заметки НЕ отображаются** на публичном сайте
- ✅ **Доступны только в админ панели** для администраторов
- ✅ **НЕ передаются клиентам** через API
- ✅ **Хранятся только в базе данных**

## 🚀 **Применение изменений:**

### 1. Обновить базу данных

Выполните в **Supabase SQL Editor**:

```sql
-- Добавляем новый столбец для скрытых заметок
ALTER TABLE qr_codes 
ADD COLUMN IF NOT EXISTS hidden_notes TEXT;

-- Добавляем комментарий к столбцу для документации
COMMENT ON COLUMN qr_codes.hidden_notes IS 'Скрытые заметки для администратора, не отображаются на сайте';

-- Проверяем что столбец добавлен
SELECT column_name, data_type, is_nullable 
FROM information_schema.columns 
WHERE table_name = 'qr_codes' AND column_name = 'hidden_notes';
```

**ИЛИ** выполните готовый файл `add_hidden_column.sql`

### 2. Дождаться деплоя

Netlify автоматически задеплоит обновленную админ панель.

## 🎨 **Новый функционал админ панели:**

### **Форма добавления QR-кода:**
- ✅ Все существующие поля
- ✅ **Новое поле**: "Скрытые заметки (только для админа)"
- ✅ Многострочное текстовое поле для заметок

### **Список QR-кодов:**
- ✅ Показывает скрытые заметки с иконкой 📝
- ✅ Заметки отображаются курсивом и серым цветом
- ✅ Видны только администраторам

## 📋 **Примеры использования скрытых заметок:**

- **Источник QR-кода**: "Получен от поставщика ABC"
- **Особенности**: "Работает только в Германии"
- **Проблемы**: "Иногда не активируется с первого раза"
- **Контакты**: "Поставщик: +49 123 456 789"
- **Дата получения**: "Закуплен 15.09.2025"
- **Стоимость**: "Цена: 2.50 EUR"

## 🔍 **Проверка работы:**

1. **Откройте админ панель**: `https://heyesim.me/admin-qr-upload.html`
2. **Добавьте QR-код** с заметками в поле "Скрытые заметки"
3. **Проверьте список** - заметки должны отображаться с иконкой 📝
4. **Проверьте сайт** - заметки НЕ должны отображаться клиентам

## 🛡️ **Безопасность подтверждена:**

### ❌ **Скрытые заметки НЕ передаются:**
- В API для клиентов (`order-handler.js`)
- На страницу успеха (`success-new.html`)
- В публичные функции

### ✅ **Скрытые заметки доступны только:**
- В админ панели для авторизованных администраторов
- В базе данных Supabase
- В серверных функциях (при необходимости)

## 📊 **Структура таблицы qr_codes:**

```sql
CREATE TABLE qr_codes (
    id SERIAL PRIMARY KEY,
    plan_id INTEGER REFERENCES esim_plans(id),
    qr_url VARCHAR(255) NOT NULL UNIQUE,
    country_name VARCHAR(100),
    country_code VARCHAR(10),
    esim_number VARCHAR(50),
    pin_code VARCHAR(20),
    puk_code VARCHAR(20),
    hidden_notes TEXT,  -- ← НОВЫЙ СТОЛБЕЦ
    is_used BOOLEAN DEFAULT FALSE,
    order_id TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    used_at TIMESTAMP WITH TIME ZONE
);
```

## 🎯 **Готово к использованию!**

После выполнения SQL скрипта админ панель будет поддерживать скрытые заметки для каждого QR-кода.
