# 📊 Функции экспорта данных

## 🎯 **Обзор**

Добавлены функции экспорта всех заказов и QR-кодов из админ панели в формате JSON для анализа и резервного копирования.

## 🚀 **Новые функции**

### **1. Экспорт заказов** (`/.netlify/functions/export-orders`)

**Что экспортируется:**
- ✅ Все заказы с полной информацией
- ✅ Данные о тарифах eSIM
- ✅ История платежей
- ✅ Статусы заказов
- ✅ Информация о клиентах

**Структура данных:**
```json
{
  "export_date": "2024-01-15T10:30:00.000Z",
  "total_orders": 150,
  "orders": [
    {
      "id": "order-uuid",
      "email": "customer@example.com",
      "phone": "+1234567890",
      "plan_name": "Стандарт",
      "plan_price": 9.99,
      "plan_data_limit": "5GB",
      "plan_validity": 30,
      "plan_country": "США",
      "status": "paid",
      "created_at": "2024-01-15T10:00:00.000Z",
      "updated_at": "2024-01-15T10:05:00.000Z",
      "qr_code_assigned": "Yes",
      "qr_code_id": "qr-uuid",
      "payments": [
        {
          "payment_id": "payment-uuid",
          "amount": 9.99,
          "currency": "USD",
          "status": "completed",
          "payment_method": "card",
          "transaction_id": "txn_123456",
          "created_at": "2024-01-15T10:02:00.000Z"
        }
      ]
    }
  ]
}
```

### **2. Экспорт QR-кодов** (`/.netlify/functions/export-qr-codes`)

**Что экспортируется:**
- ✅ Все QR-коды с полной информацией
- ✅ Данные о тарифах
- ✅ Статус использования
- ✅ Скрытые заметки (только для админа)
- ✅ Информация о связанных заказах

**Структура данных:**
```json
{
  "export_date": "2024-01-15T10:30:00.000Z",
  "total_qr_codes": 500,
  "available_qr_codes": 350,
  "used_qr_codes": 150,
  "qr_codes": [
    {
      "id": "qr-uuid",
      "plan_name": "Премиум",
      "plan_price": 19.99,

      "plan_country": "Европа",
      "country_name": "Германия",
      "country_code": "DE",
      "esim_number": "+49123456789",
      "pin_code": "1234",
      "puk_code": "56789012",
      "qr_url": "https://example.com/qr-code.png",
      "is_used": false,
      "created_at": "2024-01-15T10:00:00.000Z",
      "updated_at": "2024-01-15T10:00:00.000Z",

        "order_status": "paid",
        "order_created_at": "2024-01-15T10:05:00.000Z"
      }
    }
  ]
}
```

## 🎨 **Интерфейс админ панели**

### **Расположение:**
- 📍 **Место:** После статистики, перед формой добавления QR-кодов
- 🎨 **Дизайн:** Современные кнопки с градиентами
- 📱 **Адаптивность:** Работает на всех устройствах

### **Кнопки:**
1. **📋 Экспорт заказов** - зеленая кнопка
2. **🔗 Экспорт QR-кодов** - синяя кнопка

### **Статус экспорта:**
- ⏳ **Загрузка** - показывает прогресс
- ✅ **Успех** - зеленое уведомление с количеством записей
- ❌ **Ошибка** - красное уведомление с описанием ошибки

## 🔒 **Безопасность**

### **Авторизация:**
- ✅ Требуется токен админа
- ✅ Проверка сессии
- ✅ Использование `service_role` ключа

### **Доступ к данным:**
- ✅ Только авторизованные админы
- ✅ Полный доступ к данным через `service_role`
- ✅ CORS настроен правильно

## 📁 **Файлы**

### **Netlify Functions:**
- `netlify/functions/export-orders.js` - экспорт заказов
- `netlify/functions/export-qr-codes.js` - экспорт QR-кодов

### **Админ панель:**
- `admin-qr-upload.html` - обновлена с кнопками экспорта

## 🚀 **Использование**

### **1. Войдите в админ панель:**
```
https://heyesim.me/admin-qr-upload.html
```

### **2. Найдите секцию "Экспорт данных"**

### **3. Нажмите нужную кнопку:**
- **📋 Экспорт заказов** - для выгрузки всех заказов
- **🔗 Экспорт QR-кодов** - для выгрузки всех QR-кодов

### **4. Файл автоматически скачается:**
- `orders_export_YYYY-MM-DD.json`
- `qr_codes_export_YYYY-MM-DD.json`
