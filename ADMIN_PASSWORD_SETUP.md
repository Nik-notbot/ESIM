2. Выберите ваш сайт
3. Перейдите в **Site settings → Environment variables**
4. Добавьте новую переменную:
   - **Key**: `ADMIN_PASSWORD`
   - **Value**: `JlHhWO2hoU2`

### Шаг 2: Перезапустить деплой
После добавления переменной окружения:
1. Перейдите в **Deploys**
2. Нажмите **Trigger deploy → Deploy site**

### Вариант 1: Через Netlify CLI
