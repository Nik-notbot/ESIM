# 🔧 Диагностика 500 ошибок в функциях экспорта

## 🚨 **Проблема:**
- ✅ Supabase подключение работает
- ✅ Админ панель загружается
- ❌ Функции экспорта возвращают 500 ошибки

## 🔍 **Диагностика:**

### **1. Протестируйте упрощенные функции:**
После деплоя проверьте:
- `https://heyesim.me/.netlify/functions/export-orders-simple`
- `https://heyesim.me/.netlify/functions/export-qr-codes-simple`

### **2. Проверьте логи Netlify:**
1. **Netlify Dashboard** → Functions → View logs
2. **Найдите ошибки** в логах функций экспорта
3. **Проверьте** детали ошибок

### **3. Возможные причины 500 ошибок:**

#### **A. Проблемы с JOIN запросами:**
- Сложные JOIN с таблицей `esim_plans` могут вызывать ошибки
- RLS политики могут блокировать доступ к связанным таблицам

#### **B. Проблемы с RLS политиками:**
- Политики могут блокировать доступ к данным
- Service role может не иметь прав на все таблицы

#### **C. Проблемы со структурой данных:**
- Отсутствующие таблицы или колонки
- Неправильные типы данных

## 🛠️ **Исправления:**

### **1. Созданы упрощенные функции:**
- `export-orders-simple.js` - без сложных JOIN
- `export-qr-codes-simple.js` - без сложных JOIN
- Ограничение до 10 записей для тестирования

### **2. Улучшено логирование:**
- Подробные логи в консоль
- Детальная информация об ошибках
- Проверка каждого шага

### **3. Упрощены запросы:**
- Убраны сложные JOIN
- Простые SELECT запросы
- Базовая обработка данных

## 🚀 **Тестирование:**

3. **Нажмите "🔗 Экспорт QR-кодов"** - должен использовать упрощенную функцию

### **Шаг 2: Проверьте результат**
Должны скачаться JSON файлы с базовыми данными:
- Заказы без связанных данных о тарифах
- QR-коды без связанных данных о заказах

### **Шаг 3: Если упрощенные функции работают**
Значит проблема в сложных JOIN запросах. Можно:
1. **Использовать упрощенные функции** для базового экспорта
2. **Исправить JOIN запросы** в оригинальных функциях
3. **Настроить RLS политики** для связанных таблиц
