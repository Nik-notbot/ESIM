# Инструкция по настройке сайта eSIM Store

## 1. Настройка базы данных Supabase

1. Зайдите в панель управления Supabase
2. Перейдите в SQL Editor
3. Выполните SQL скрипт из файла `database_schema.sql`
4. Добавьте QR-коды в таблицу `qr_codes`:
   ```sql
   INSERT INTO qr_codes (plan_id, qr_url) VALUES
   (1, 'https://ibb.co/ваша-ссылка-1'),
   (1, 'https://ibb.co/ваша-ссылка-2'),
   (2, 'https://ibb.co/ваша-ссылка-3'),
   (2, 'https://ibb.co/ваша-ссылка-4');
   ```

## 2. Настройка Webhook

### Вариант 1: Vercel
1. Создайте файл `api/webhook.js` в корне проекта
2. Скопируйте код из `webhook-handler.js`
3. Добавьте переменные окружения в Vercel:
   - `SUPABASE_SERVICE_KEY` - получите из настроек проекта Supabase

### Вариант 2: Собственный сервер
1. Установите зависимости:
   ```bash
   npm install express @supabase/supabase-js
   ```
2. Создайте Express сервер с endpoint `/webhook/wata`
3. Используйте код из `webhook-handler.js`

## 3. Настройка платежной системы Wata

1. В личном кабинете Wata настройте Webhook URL:
   - Для Vercel: `https://ваш-домен.vercel.app/api/webhook`
   - Для собственного сервера: `https://ваш-домен.com/webhook/wata`

2. Убедитесь, что в настройках включены события:
   - `payment.succeeded`
   - `payment.failed`

## 4. Важные замечания по безопасности

1. **НИКОГДА** не используйте `anon` ключ Supabase на сервере
2. Используйте `service_role` ключ только в серверном коде
3. Добавьте проверку подписи webhook (если Wata поддерживает)
4. Настройте CORS политики в Supabase для вашего домена

## 5. Тестирование

1. Добавьте тестовые QR-коды в базу данных
2. Проверьте работу покупки с тестовой картой
3. Убедитесь, что webhook правильно обрабатывает платежи
4. Проверьте, что QR-коды корректно выдаются после оплаты

## 6. Мониторинг

Рекомендуется настроить:
- Уведомления когда заканчиваются QR-коды для тарифа
- Логирование всех webhook событий
- Мониторинг неуспешных платежей

## 7. Email уведомления (опционально)

Для отправки QR-кодов на email можно использовать:
- SendGrid
- Mailgun
- AWS SES
- Или встроенные функции Supabase

Добавьте соответствующий код в `webhook-handler.js`
