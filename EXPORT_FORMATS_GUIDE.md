# 📊 Руководство по форматам экспорта

## 🎯 **Обзор**

Добавлена поддержка экспорта данных в различных форматах:
- ✅ **CSV** - табличный формат для Excel/Google Sheets
- ✅ **Excel (.xls)** - нативный формат Excel
- ✅ **JSON** - структурированные данные для разработки

## 🚀 **Новые функции экспорта**

### **1. Экспорт заказов:**

#### **CSV формат** (`export-orders-csv.js`):
- **Файл:** `orders_export_YYYY-MM-DD.csv`
- **Кодировка:** UTF-8 с BOM для корректного отображения в Excel
- **Столбцы:**
  - ID заказа
  - Email клиента
  - Телефон клиента
  - ID тарифа
  - Статус
  - Дата создания
  - Дата обновления
  - ID QR-кода

#### **Excel формат** (`export-orders-excel.js`):
- **Файл:** `orders_export_YYYY-MM-DD.xls`
- **Формат:** HTML таблица, открываемая в Excel
- **Столбцы:** Те же, что и в CSV

#### **JSON формат** (`export-orders-simple.js`):
- **Файл:** `orders_export_YYYY-MM-DD.json`
- **Структура:** Полные данные с метаинформацией

### **2. Экспорт QR-кодов:**

#### **CSV формат** (`export-qr-codes-csv.js`):
- **Файл:** `qr_codes_export_YYYY-MM-DD.csv`
- **Кодировка:** UTF-8 с BOM
- **Столбцы:**
  - ID QR-кода
  - ID тарифа
  - Страна
  - Код страны
  - Номер eSIM
  - PIN код
  - PUK код
  - URL QR-кода
  - Статус использования
  - Дата создания
  - Дата обновления
  - Скрытые заметки

#### **Excel формат** (`export-qr-codes-excel.js`):
- **Файл:** `qr_codes_export_YYYY-MM-DD.xls`
- **Формат:** HTML таблица, открываемая в Excel
- **Столбцы:** Те же, что и в CSV

#### **JSON формат** (`export-qr-codes-simple.js`):
- **Файл:** `qr_codes_export_YYYY-MM-DD.json`
- **Структура:** Полные данные с метаинформацией

## 🔧 **Технические детали**

### **CSV формат:**
- **Разделитель:** запятая (,)
- **Экранирование:** кавычки для значений с запятыми
- **Кодировка:** UTF-8 с BOM для Excel
- **Переносы строк:** поддерживаются

### **Excel формат:**
- **Технология:** HTML таблица с MIME-типом Excel
- **Совместимость:** Excel, LibreOffice, Google Sheets
- **Форматирование:** границы таблицы, заголовки

### **JSON формат:**
- **Структура:** вложенные объекты с метаданными
- **Кодировка:** UTF-8
- **Форматирование:** отступы для читаемости

## 🎯 **Преимущества разных форматов**

### **CSV:**
- ✅ **Универсальность** - открывается везде
- ✅ **Компактность** - маленький размер файла
- ✅ **Совместимость** - работает с любыми табличными редакторами

### **Excel:**
- ✅ **Нативная поддержка** - открывается напрямую в Excel
- ✅ **Форматирование** - сохраняет структуру таблицы
- ✅ **Удобство** - двойной клик для открытия

### **JSON:**
- ✅ **Структурированность** - полные данные с метаинформацией
- ✅ **Программная обработка** - легко парсится
- ✅ **Расширяемость** - можно добавлять новые поля
